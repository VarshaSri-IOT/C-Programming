 # C Programming: Preprocessor Directives and Macros

This folder contains C programs demonstrating preprocessor directives and macros.

## Topics Covered

1. Object-like macros using `#define`
2. Multiple macro definitions
3. Removing and redefining macros using `#undef`
4. Function-like macros
5. Finding the maximum of two numbers
6. Conditional compilation using `#ifdef`
7. Conditional compilation using `#ifndef`
8. Predefined macros such as `__FILE__`, `__LINE__`, `__DATE__`, and `__TIME__`

## Learning Objective

To understand how the C preprocessor works and how macros and conditional compilation are used in C programming.

## Compilation

Compile an individual program using GCC:


gcc 04.square-macro.c -o square
```

Run it on Linux:

./square
```

On Windows, run:

```powershell
.\square.exe
```
